# CrewHighlightJobAndSalary - ΔV: Rings of Saturn

Version 1.0.1. Makes the **job** and the **salary** of every crew entry (hired and
unhired) stand out when scanning the crew screens:

- **Job:** bright yellow.
- **Salary:** amber.
- **Name, education, experience, next salary due, leave until:** dimmed gray, so the two above pop.

## Install
1. In the game folder (next to `Delta-V.exe`), create a folder named `mods`.
2. Put `CrewHighlightJobAndSalary-1.0.1.zip` in it. Do not unzip it.
3. Launch the game with `--enable-mods`.

To change a color, edit `JOB_COLOR`, `SALARY_COLOR` or `DIM_COLOR` at the top of
`CrewHighlightJobAndSalary/ModMain.gd` inside the zip (red, green, blue, each 0 to 1).

Mods are unofficial and can break after game updates. Keep a backup of your save.
